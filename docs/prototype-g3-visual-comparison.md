# Visual comparison — public pilot prototype vs G3 functional preview

**Date checked:** 22 October 2026. **Purpose:** internal design adaptation only; not editorial approval or publication.

## Sources reviewed
- Live reference: https://bretos.vercel.app/ (HTTP 200; project-pilot labeling visible).
- G3 source: repository branch `g3-functional-preview`, source baseline `a3043bea5c0f0856132803cf79295f7b7542c8f0`; approved G3 code milestone remains `e82e012569af75d34b2319471a8377eb3ee907fe`.

- Prototype-derived visual asset: public logo PNG is included solely as a draft visual asset; it is not designated the master logo.

## Findings and disposition

| Attribute | Prototype | G3 baseline | Preview disposition |
|---|---|---|---|
| Palette | Turquoise `#18C7C8`, near-black `#0A0A0A`, charcoal `#2D2D2D`, light gray `#F4F4F4`, white | Same neutral/turquoise base, mostly flat white and soft-gray sections | Retain shared palette; use black as primary hero action and teal as restrained accent. |
| Identity | Horizontal stylized wordmark/isotype; striking, graphic-led brand treatment | Dashed “B” placeholder and text brand name | Replace placeholder in preview with a locally bundled prototype-derived logo; add an explicit “not final identity” note. No claim of master/final logo. |
| Typography / hierarchy | Large bold headline, compact uppercase turquoise eyebrow, spacious composition | Smaller centered headline and quieter catalog-led hero | Adopt larger responsive headline and eyebrow, retaining the existing G3 wording and draft banner. |
| Layout | Split hero with visual panel; strong CTA; distinct neutral sections | Centered hero, product cards, pilot caveat | Use split responsive hero and a brand-reference panel; keep catalog cards and existing sections/flows. |
| Product imagery | Product mockups and carousel are explicitly presented as visual references/concepts | No product image in G3 | Do not import a product mockup into this pass, to avoid implying validated production output. |
| Copy/function | New positioning, product lines, FAQs, evaluation form; prototype explicitly says form is inert pending backend/responsible parties | G3's existing draft copy, G1 catalog states, no operational form | Do not transfer prototype copy or form/function. Preserve G3 content/state controls and noindex safeguards. |
| Mobile | Clean, relatively large, single-column presentation | Compact but conventional; mobile menu shown open in saved G3 capture | Keep G3 navigation; scale hero and brand panel to one column, make CTAs full width. |

## Not carried forward
Prototype's slogan/marketing text, claims about services/process, customer eligibility copy, product images/mockups, FAQ, and all form fields/data handling. The public prototype is an unfinished pilot and is a visual reference only; its functionality and wording are not final approved content.
